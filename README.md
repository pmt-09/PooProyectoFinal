# Sistema de Gestión de Biblioteca - POO

Proyecto final de Programación Orientada a Objetos

## Descripción
Sistema de biblioteca desarrollado en Java que permite:
- Gestionar usuarios (Clientes y Administradores)
- Buscar y gestionar libros
- Realizar préstamos y devoluciones
- Control de multas

## Estructura del Proyecto
elementosdeprogramacion/
└── convocatoria/
├── Admin.java
├── Cliente.java
├── Libro.java
├── Usuario.java
├── Ubicacion.java
└── Poo.java (Clase principal)
## Cómo ejecutar el proyecto

1. Abrir el proyecto en VS Code o cualquier IDE de Java
2. Compilar todas las clases
3. Ejecutar la clase principal: `Poo.java`
4. Seguir el menú que aparece en consola

## Requisitos
- Java JDK 14 o superior
- Entorno de desarrollo (VS Code, Eclipse, NetBeans, etc.)
